# Tonkl Private Testnet Tester Invitation

Use this as the base message for trusted private-alpha testers.

```text
Hey, we are opening a small private Tonkl testnet round and I would like you to help test it.

Important safety notes first:
- This is a testnet only.
- Do not use real funds.
- Do not paste or import a real seed phrase.
- Use a fresh dummy wallet created just for testing.
- Testnet tokens have no real-world value.
- If anything asks for a seed phrase, private key, or passphrase in chat, stop and report it.

What we need tested:
1. Create or unlock a test wallet.
2. Receive faucet tokens.
3. Check your balance.
4. Send test tokens to another test wallet.
5. Receive test tokens.
6. View transaction history.
7. Try Tonkl AI for safe guidance, balance help, and preview-only flows.
8. Try token creation only if the UI says it is ready.

Things that should never happen:
- Tonkl AI should never reveal private keys or seed phrases.
- Tonkl AI should never send funds by itself.
- A transaction should never execute without a clear preview and confirmation.
- Website errors should not show file paths, stack traces, private keys, or wallet database paths.

Please report bugs with:
- What you were trying to do
- Exact steps to reproduce
- What you expected
- What actually happened
- Screenshot or short log if available
- Whether wallet balance or history changed unexpectedly

This is early private testing, so rough edges are expected. The priority is safety, wallet correctness, and finding anything confusing before a wider public testnet.
```
